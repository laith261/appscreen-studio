Add the snippet below to your AI assistant's MCP configuration file. Replace the path with the location of your cloned repository.

  "mcpServers": {
    "appscreen": {
      "command": "node",
      "args": ["/path/to/appscreen/mcp/server.js"]
    }
  }
}

Every capability available in the studio interface is exposed to AI agents with full validation and error recovery:

Tool Name Category Description Key Parameters
create_project Project Generates a compliant store listing with phone/tablet dimensions or from curated templates. project_name, template_id, canvas_preset
inspect_project Audit Returns structured metadata, screen counts, char lengths, device frames, and compliance state. file_path, project_data
add_screen Canvas Appends a new styled screen with headlines, subtitles, gradient backgrounds, and badges. headline_text, subtitle_text, color1, color2
update_screen Canvas Modifies texts, colors, custom fonts, tilt rotation, scale, and embeds local app screenshots. screen_index_or_id, headline_font, screenshot_path
remove_screen Canvas Removes a screen from the project by numeric index or ID. screen_index_or_id
apply_palette Theme Applies a curated gradient/solid color palette across all screens or to a specific screen in one call. palette_id, screen_index_or_id
list_fonts Typography Queries Google Fonts and returns recommended default fonts per language (Arabic, Japanese, etc.). language_code
list_palettes Theme Lists curated listing themes: Electric Indigo, Cyber Emerald, Sunset Coral, Obsidian & Gold. (none)
list_templates Templates Lists ready-made Play Store listing templates (SaaS, Dark Fintech, Fitness, Food Delivery, Travel). category
get_template Templates Retrieves complete screen layers, typography, and styling for a template ID. template_id
list_devices Device Returns supported mockups: modern punch-hole flagship, minimalist phone, frameless, and tablets. (none)
list_badges Badges Lists trust badges, rating pills (★ 4.9), download counters (🚀 50M+), and floating UI cards. category
add_badge_to_screen Badges Inserts a rating seal, floating notification toast, or security badge onto a screen. screen_index_or_id, label, badge_type
localize_project i18n Localizes listing into any language with native RTL mirroring and Arabic Cairo typography. language_code, translations
generate_feature_graphic Store Asset Creates the mandatory 1024×500 Google Play Feature Graphic matching listing branding. headline_text, subtitle_text, color1
validate_project Compliance Strict ASO audit: screen counts (4–8), char limits (<45 hl, <85 sub), and missing assets. file_path, project_data
render_screen_svg Visual Renders self-contained vector SVG representation for headless visual inspection without a browser. screen_index_or_id, language_code
save_project_file Storage Saves an AppScreen project JSON object to a designated file path on disk. file_path, project_data
load_project_file Storage Loads and parses an AppScreen project JSON file from disk. file_path
